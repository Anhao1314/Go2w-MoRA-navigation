# MoRA 阶段2（简化版）：多段路径 A→B 脚本控制器 P0 验证报告

生成时间：2026-08-22

## 1. 环境扩展总结

- `rl/go2w_env.py` 新增 `multi_segment`、`segments`、`subgoal_switch` 参数（默认 `False`，单段行为完全不变）；
- 段1：`x∈[0.8,4.3]`，振幅 0.12，走廊半宽 0.50；段2：`x∈[4.3,10.8]`，振幅 0.35，走廊半宽 0.40；
- A=(4.3,0)，B=(10.8,0)；子目标精确停止：容差 ±0.15m + 停留 0.3s + 速度 <0.2m/s；
- 走廊墙：段1/段2 各 8 段，共 16 个 box body（运行时 body_pos/body_quat 旋转）；
- 新增方法：`_current_segment/_segment_center_y/_segment_tangent_angle/_segment_deviation/_check_subgoal_reached/_switch_to_next_segment`；
- 多段任务 episode 时长扩展为 30s（默认单段仍为 15s）。

> 注：按给定公式，A 点切线角存在小拐角（段1终点 0.212 rad，段2起点 0.326 rad，差约 0.11 rad），
> 属于任务参数本身的不连续；脚本控制器用前视跟踪可以平滑过渡，报告中如实记录。

## 2. 脚本控制器适配总结

- 新建 `scripts/gen_demo_multi_segment.py`，不修改原单段演示脚本；
- 纯跟踪前视点 lookahead=0.7m + 差速转向 `bias=clip(-2.5·ang_err+0.5·dev, ±1.0)` + 四轮全驱 forward=0.12；
- 距当前子目标 <0.8m 线性减速至 0.3，<0.3m 降至 0.4；进入容差后若速度超标施加反向制动，否则零力矩保持；
- 环境在 A/B 点完成精确停止判定后自动切段/完成任务；控制器无需内部状态机。

## 5. 失败模式分析

- 主实验无失败；
- 测试 A 的失败说明：**A 点精确停止/减速是必要的**——不停车高速通过 A 点后，
  段2起始段曲率突变导致控制器无法在窄走廊内收敛（max_dev 仍在走廊内，属摔倒/动力学失稳）；
- 噪声 0.03 的 2 条失败为高速过弯时的累积偏差，验证了纯反应式控制器在较大扰动下的局限。

## 7. 结论与建议

- **验收通过**：20/20 成功率（≥90%）、A 点停止 100%（≥80%）、全程走廊内、平均 14.28s（<30s）、向后兼容、170 项测试 + Pyright 0 errors；
- 任务难度评估：对 RL 属**中等偏难**——两段不同曲率 + 精确停止 + 顺序子目标，比单段 curve 更复杂；
- 纯反应式控制器局限：A 点不停车/大噪声（0.03）下失败，说明需要“目标/状态记忆 + 速度规划”等高阶能力（MoRA System 1/2 的价值点）；
- 下一步 RL 建议：
  - 观测：加入当前段索引、到当前子目标距离/航向、是否需停靠；
  - 奖励：段切换成功 + 子目标到达稀疏奖励，精确停止给予明确奖励，避免“高速冲过”；
  - 初始化：可用本脚本控制器的成功轨迹做 BC 预热（`curve_multi_segment_demo_main_seedXX.npz`，obs 决策前帧对齐）。

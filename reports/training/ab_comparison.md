# A/B 对比报告：单层 vs 分层（L1 任务）

- **日期**：2026-10-23
- **任务**：`Go2Loco-Sequence-v0`（L1：前进 1.2 m → 停止并保持 0.5 s）
- **评估**：冻结种子 E={0..19}，20 episodes，同一停止判据
- **对比组**
  - **A 单层**：53 维观测 → 12 维关节，PPO
  - **B 分层**：53 维观测 → 2 维速度指令 → 冻结 S0 locomotion 策略（M1 seed 0）→ 12 维关节

两组使用**相同的环境、奖励函数、观测、PPO 超参、迭代数（1500）和种子**。

## 1. 最终性能（1500 迭代的 checkpoint）

| 指标 | A 单层 | B 分层 |
| --- | --- | --- |
| 成功率 | **1.00（20/20）** | **1.00（20/20）** |
| 平均完成步数 | 563.95（11.3 s） | **97.8（2.0 s）** |
| 摔倒率 | 0.00 | 0.00 |
| 训练末 reward | 42.95 | 50.95 |

**结论**：L1 上两者都完全解决（符合 H2：分层不是银弹）。完成效率上分层快 **5.8 倍**，
但这主要反映"2 维指令直接给出全速前进/停止"的动作抽象优势，不是成功率差异。

## 2. 样本效率（关键结果）

对训练中间 checkpoint 逐个评估同 20 个种子（粗扫 100 步粒度 + 细扫 50 步粒度，受
checkpoint 保存间隔限制）：

| 迭代 | A 单层成功率 | B 分层成功率 |
| --- | --- | --- |
| 0 | 0.00 | **0.75** |
| 50 | 0.00 | **1.00** |
| 100 | 0.00 | 1.00 |
| 150 | **1.00** | 1.00 |
| 200 | 1.00 | 1.00 |
| 300–1499 | 1.00 | 1.00 |

曲线：`media/training/sweep_ab_comparison.png`

**结论（按 50 迭代粒度）**：

- **B 在 50 迭代达到 100%，且迭代 0（未训练）就有 75%**——S1 动作空间小到随机策略
  也能碰对相当比例的 episode；
- **A 在 150 迭代达到 100%，与 B 的差距为 100 迭代（约 2–3 倍）**；
- A 的收敛是相变式的（100 迭代 0% → 150 迭代 100%），B 从 75% 平滑爬到 100%。

局限必须写明：

1. 粒度 50 迭代（checkpoint 保存间隔），真实收敛点分别在 (50,100]（B 可能更早）与
   (100,150]（A）；倍数按区间上下界为 **1.5–3 倍**。
2. 每个训练条件只有 **1 个训练种子**，没有跨种子方差；结论是单次观测。
3. **B 的 S0 来自 M1 预训练（约 1200 秒），没有计入 B 的训练预算**。B 在迭代 0 就有
   75% 成功率，正说明优势主要来自预训练 S0 提供的动作抽象，而不是 S1 本身学得快——
   公平的"从零总成本"口径下，B = S0 训练 + S1 训练 > A。分层的真实收益在
   **S0 复用**：同一 S0 服务第二个及以上任务时，边际成本只有 S1。

## 3. 对假设的支持程度

| 假设 | 证据 | 判定 |
| --- | --- | --- |
| H1 分层样本效率更高 | 50 迭代 100% vs 150 迭代 100%；迭代 0 时 B 已有 75% | **部分支持**（单种子；优势主要来自预训练 S0 的动作抽象，S1 本身学习增益需与"随机 S1"对照才能分离） |
| H2 简单任务上无差异 | 最终成功率都是 1.00 | **支持** |
| H3 分层失败可归因 | 尚未在 L2/L3 触发失败 | 未检验 |
| H4 接口损失可量化 | 未测量 S0 跟踪误差对整体上限的影响 | 未检验 |

# ADR-003：A/B/C 实验共用同一策略权重

- **状态**：接受
- **日期**：2026-10-23
- **相关**：[架构 v0.2 §6](../ARCHITECTURE_V2.md#6-实验设计)

## 背景

实验要比较三种仲裁配置：

- A：无仲裁（v0.1 行为）
- B：固定阈值
- C：自适应阈值

如果每种配置单独训练策略，性能差异会混入训练随机性（不同种子、不同收敛点），无法归因到仲裁层本身。单卡训练预算也支撑不起 3 配置 × 3 场景 × 3 种子的组合。

## 选项

1. **每配置独立训练**：最"公平"（策略会适应仲裁），但成本 ×3，且结论仍受种子方差影响。
2. **共用同一策略权重，只切换仲裁层**：成本低，差异完全来自仲裁层，但测的是"零样本加装仲裁"的效果，不含策略适应。
3. **混合**：A/B/C 共用权重做主实验，另做一个"策略适应仲裁"的小规模验证（1 个种子）。

## 决定

选择选项 2 作为主实验，选项 3 的适应实验列为加分项（若 W3 有余力）。

## 后果

**正面**

- 结论干净：任何指标差异只能来自仲裁层。
- 实验成本从"再训 3 个模型"降到"只跑评估"，排期可控。
- 三种子策略权重可复用，评估脚本一次跑完 A/B/C。

**负面 / 风险**

- 无法回答"策略能否学会适应该仲裁层"；报告中必须明确这一边界。
- 若仲裁干预很强，零样本适配的结论可能低估其潜力（也可能高估其代价）。

**跟进**

- 报告"局限"一节必须写明：结论适用于"零样本加装仲裁"，不含策略适应。
- 若时间允许，补一个种子做适应实验，对比零样本 vs 适应后的干预率。

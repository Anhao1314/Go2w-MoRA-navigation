# MoRA-inspired 分层控制架构

本项目验证的核心假设：**单层 PPO（61 维观测 → 6 维动作）是“纯反射式”策略，
缺乏目标概念与进度闭环，在长程导航任务上容易学到“不动”或“乱动”的局部最优。**
项目参考公开的 MoRA / Agentic-Native 三层思想，将控制器拆成三个可分别验证的层级，
用仓库内实验检验“分层控制 + 动作空间降维 + 目标条件”是否有效。

> **命名边界**：这里的 `MoRA-inspired` 是独立的工程化映射，不是墨奇官方模型、
> 参数或训练流程的复现。当前 System 2 是规则决策器，System 1 是 PPO MLP，
> System 0 是脚本/PD 控制器；仓库没有声称实现通用 VLM/VLA 或开放世界 Agent。

## 三层结构

```text
System 2（规则决策 / 未来可替换为大 VLM）
  ├─ 任务意图：A→左分支、B→右分支
  └─ 在决策区（x∈[1.8,2.2]）一次性锁定分支，并把决策写回观测

System 1（高层导航策略，PPO MLP [256,256]）
  ├─ 输入：61 维底层观测 + 目标/进度/决策观测（63/67/68 维）
  ├─ 输出：2 维高层动作 [speed_scale, turn_adjust]
  └─ 目标维护：到子目标距离、航向误差、精确停止计时

System 0（低层运动控制器，脚本/PD）
  ├─ 前视点跟踪：lookahead=0.7m + 差速转向 bias=clip(-2.5·herr+0.5·dev, ±1.0)
  ├─ 四轮全驱基础力矩 0.12（×15 Nm）
  └─ 把 2 维高层指令展开为 6 维低层动作
```

## 观测演进

| 版本 | 维度 | 追加内容 | 对应能力 |
| --- | --- | --- | --- |
| 单层 PPO | 61 | 底层状态（姿态/轮速/导航 9 维） | 纯反射 |
| B+ 随机目标 | 63 | remaining_arc + target_heading | Goal-Conditioned |
| 多段 A→B | 67 | segment_idx / dist_to_subgoal / 航向 sin/cos / docking / passed | 目标+进度+记忆 |
| 岔路口 | 68 | target onehot / branch onehot / dist_junction / dist_goal / system2_flag | System 2 决策 |

## 关键机制

- **动作空间降维**：6 维力矩 → 2 维导航指令；`speed_scale∈[0.9,1.5]` 禁止停车，
  消除"站桩"局部最优（实验 A 步骤的干净消融）。
- **BC 预热**：用脚本控制器轨迹监督训练 actor（MSE），再进入 PPO 微调；
  多段任务为 stage1/stage2 分别生成演示，避免起始状态分布不匹配。
- **三阶段课程**：段1→A → 段2→B → 完整 A→B，每阶段用上一阶段 best 初始化，
  连续 5 个评估点达标自动切换。
- **精确停止**：位置 ±0.15m + 停留 0.3s + 速度 <0.2m/s 三条件同时满足；
  一次性发 +100 停靠奖励，B 点到达即终止，防止冲过终点。
- **System 2 规则决策**：岔路口任务在决策区按目标锁定分支，决策正确 +30、
  错误 -30；高层策略只负责在锁定分支后导航。
- **工程闭环**：训练守护（崩溃续训）、Web 面板（实时进度/资源/报告）、
  自动演示视频、197 项单元测试 + Pyright 0 errors。

## 实验结论

- 单层 PPO / BC / DAgger 在弯道上全部失败（≤0.7m），分层后单段 100%。
- 随机目标多样化下，Goal-Conditioned 与无目标对照均可达到 90%~100%，
  目标条件在有分支决策的复杂任务上才体现出独立价值。
- 多段 A→B（10m）与岔路口任务最终 100% 成功率、0 摔倒。

## 架构边界与替换点

| 层级 | 当前实现 | 已验证内容 | 后续可替换方向 |
| --- | --- | --- | --- |
| System 2 | 目标到分支的规则映射 | 决策接口、锁定机制、观测回写 | 规划器、VLM/VLA、带约束的策略模块 |
| System 1 | SB3 PPO MLP | 目标/进度条件下的导航修正 | recurrent policy、Transformer、离线/模型式 RL |
| System 0 | 前视点 + 差速脚本控制 | 稳定执行、演示生成、低层动作展开 | 实机厂商控制器、学习型 locomotion policy |
| Environment | MuJoCo | 指定地形与任务协议 | 域随机化、真实传感、执行时延与 sim-to-real |

三层之间通过窄接口解耦，因此替换某一层时可以保留其余层的评估协议。当前实验只证明
这种拆分在仓库任务集上有效，不证明任意上层模型或任意真实场景都能直接复用。
